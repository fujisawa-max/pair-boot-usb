PAIR Boot USB toolkit

Start with QUICK-START.md, then DETAILS.md.
Default Windows storage: D: / GPU-Linux; select another target in the GUI.
Candidate export does not authorize Linux writes. Validate and register on the target PC using Fedora.
Back up inventory JSON and the registry before reflashing. Restore using the registry deployment tools.
Do not replace the new USB certificate or tools with old copies.
The owner performs MOK operations explicitly. No private signing key belongs on the USB.
