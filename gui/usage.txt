GPU Linux 管理GUI — 使い方

このウィンドウを開いたまま、管理GUIの操作を続けられます。

PC登録一覧（台帳）とは
各PCの識別情報（UUID）、確認済みのLinux保存先、GPUなどをまとめた
プロジェクト独自の登録ファイルです。候補JSONをFedoraで確認・登録すると
作られます。「台帳」はFedoraやgpu-unlockの正式な用語ではありません。

Windows：候補情報の作成
1. 「環境確認」で対象ドライブと検査結果を確認します。
2. 「候補情報を保存」で保存先NTFSドライブとフォルダ名を選びます。
   既定は D: / GPU-Linux。外付け保存先ならUSB指定にチェックします。
3. 「選択・確認して実行」。候補JSONの保存先はGPU-LOGS内にします。
4. 「候補情報を保存しました: 保存先」が表示されれば収集完了です。
   保存成功はLinuxでの利用許可ではありません。Fedoraで照合します。
   「受付できませんでした」の場合は理由を確認し、次へ進まないでください。

Fedora：保存先の登録
1. 「環境確認」でSecure Boot、GPU、領域一覧を確認します。
2. 「Windows候補から保存先・GPUを登録」で候補JSONとGPUを選択します。
3. 表示されるPC、保存先、フォルダ、検査結果を確認し、登録します。
   安全性を確認できない場合は停止します。設定を勝手に変更しません。
4. 「台帳を表示」で登録結果を確認します。

台帳の退避・復元・複数USBへの配布
・候補JSON、BitLocker観測JSON、回収済み台帳JSONはGPU-LOGS内へ戻せます。
・登録済み台帳の本体は GPU-LOGS/gpu-config/registry.json です。
・書き直したUSBへ復元する場合、退避台帳をGPU-LOGS内の別名
  （例：registry-backup.json）に置き、「USBへ台帳配布」（Fedoraでは
  「統合台帳をこのUSBへ配布」）で選びます。hostsファイルも再生成します。
・世代や内容が競合する場合は上書きせず停止します。「マージ」で確認します。
・usb-config.json、signing-cert.der、gui、toolsを古い退避物で上書きしないでください。
・複数USBは各台帳を回収→マージ→各USBへ配布します。
・Windows版も通常GPUとGPUなしTEST、0.9.0→0.9.1の台帳変換に対応します。
  未登録・GPUなしの管理PCで操作できます。新規のPC登録とMOK確認は各対象PCで行います。
・マージでは配布先のGPU-LOGSを選び、全入力・配布先より大きい世代を指定します。
  確認日は延長しません。古い版への逆変換・競合・保存先変更は停止します。
・Windowsでの詳しい操作順と実機確認項目は tools/WINDOWS-FLEET.md を参照してください。

MOK：Fedoraで操作
1. 証明書・登録状態の確認を選び、設定領域の signing-cert.der を指定します。
2. 登録を申請する場合、表示された証明書を確認し、一時パスワードを決めます。
3. 再起動後、UEFI MokManagerで所有者が最終承認します。
   MOKのパスワードはLinuxのログインパスワードとは別です。
4. 削除申請・申請取消もFedora GUIにあります。削除すると対象証明書で
   署名されたモジュールが読み込めなくなる可能性があります。

終了
ファイルを閉じ、「設定USBをアンマウント」してから安全に終了します。
root.imgを置いたUSBはLinux稼働中に抜かないでください。

詳しい手順と制限：設定領域 tools/QUICK-START.md、tools/DETAILS.md。

PAIR BOOT 0.9.1（試作）の起動・終了
・PAIR起動前にUSBを抜けるか表示します。USB CAN BE REMOVED NOWの場合だけ
  起動USBを抜けます。root/Modelsの保存USBは終了まで抜かないでください。
・1（Enter）：PAIR起動／再起動、2：PC再起動、3：電源を切る。
・PAIRをqで終了すると同じメニューへ戻ります。保存先を手動でアンマウントする必要はありません。
・root.imgに回復が必要な場合はコピー上でfsckします。元rootを保持するため追加容量が必要です。
・復旧不能や取引中断では停止します。root-backup-*や.root-maintenance.*を削除せず、Fedora保守へ進んでください。
・台帳の退避・復元と利用手順はtools/DETAILS.mdに記載しています。

0.9.1はrootとstateを分離します。0.8以前の設定は自動移行せず、新しい保存先フォルダを登録してください。
GPUなしでの起動確認:
「GPUなし確認用PC・USB保存先を登録（TEST）」を選びます。保存先の安全確認とBitLockerの確実な確認は必要です。登録後は起動メニューの「TEST / no NVIDIA GPU / USB storage only」を明示的に選択します。推論サービスは開始できません。通常のGPU登録とは区別し、rootテンプレートは0.9.1のまま使用します。

構成確認:
GPU-LOGS直下のMEDIA-INFO.txtで、プロジェクト版、root revision、kernel、gpu-unlock、Debian、Fedora、NVIDIA、PAIR、llama.cppの版を確認できます。バナーは実行中rootの情報を表示します。

ShellのBitLocker観測がUnknownの場合:
Windows GUIで「BitLocker確認JSONを保存（管理者）」を選び、対象NTFSを確認してUACを承認します。取得したJSONをFedoraの「別の観測JSONを選択する」で指定します。暗号化状態を変更する操作ではありません。
